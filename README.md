Sorting Benchmark Lab

Project Description

This project compares the performance of different sorting algorithms.

Algorithms

- Insertion Sort
- Merge Sort
- Quick Sort
- Python sorted()

Test Data

- Sorted Data
- Reversed Data
- Random Data

Input Sizes

100, 500, 1000, 2000, 5000

Tools

- Python
- Matplotlib
- CSV

How to Run

1. Install requirements:
   "pip install -r requirements.txt"
2. Run:
   "python main.py"

Output

- Benchmark Results CSV
- Sorted Chart
- Reversed Chart
